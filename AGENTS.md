# Project rules

- At the end of every work session, add a new entry to the build log for whatever was built or changed — even if the prompt for that session didn't explicitly mention it. Follow the existing format exactly: the prompt as sent, faults labeled by source ([prompt]/[output]/[defaults]/[docs]), what changed, and "the part worth keeping."
- Continue the existing entry numbering sequentially — never skip or restart it.
- Whenever the demo count or entry count changes, update the "where this is up to" stats wherever they appear (home page, concepts page) so they stay accurate.
